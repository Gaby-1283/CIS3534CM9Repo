\# CIS3534CM9Repo



\## Project Description



This repository contains the GPA 8 Python project for CIS3534C. The Python program processes network equipment data from two associated text files.



\## Project Files



\- networkFileRW.py - Python source code used to process network equipment information.

\- equip\_r.txt - Data file containing router equipment information.

\- equip\_s.txt - Data file containing switch equipment information.

\- README.md - Documentation describing the purpose and contents of this repository.



\## Project Objective



The purpose of this project is to demonstrate the use of Git and GitHub for version control, file management, tracking changes, and maintaining a remote repository.
